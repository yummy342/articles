# Aiglade 三端打通：muse、Claude Code、桌面端进同一个协作房间

Aiglade 一直想解决的问题很具体：不想学编程的人，怎么用中文指挥多个 AI Agent 干活。

现在三个入口连起来了——**muse（云端对话）、Claude Code（本地命令行）、桌面端小助理**，共用一个常驻协作房间和同一套接口，不再靠人肉传话。

## 三端是什么

- **muse**：云端的对话 agent。你在网页上跟它说话，它负责规格、审查、验证、写文档——动手之前先把事情想清楚。
- **Claude Code**：跑在你本机的命令行 agent。真正的代码树、Windows 本机、服务器、部署，都归它。
- **小助理**：桌面端 daemon 内置的助手。它在协作房间里有署名，你的每句话它都接。

以前三端之间靠人肉传话：muse 写个规格，你复制给 Claude Code；Claude Code 改完代码，你再贴回来问 muse 有没有问题。现在进同一个房间说就行了。

## 打通了什么

**一个常驻的三方协作房间。** 三方都在里面，用署名说话：`[cc]` 是 Claude Code，`[muse]` 是云端，`[assistant]` 是桌面端助手，不带前缀的就是你。

**一套协作规矩**（房间里实际在跑的）：

- 测试一律署名发言，不冒充用户——之前出过 chat token 冒充用户的事故，已经按方法拆白名单修好；
- 付费操作永远人工点头，agent 自己不花钱；
- 关键结论同时发主聊天和房间，不丢消息（这是 muse 的工作习惯）。

**文件走只读通道**：本机一个共享目录，协作方用 chat 令牌直接取，不用再每批要口令、不用人肉中转。

## 最新 skill：trichat

配合三端打通，交付 **trichat**——三方协作房间的操作 skill（已打包交付）。

- `read`：读房间消息，`--after` 按水位增量拉；
- `say`：署名发言，`--file` 直接发文件内容；
- `create`：开新房间。
- 零依赖，单文件；token 缺失直接 exit 2 不发空请求；HTTP ≥400 exit 1；未知参数 exit 2，吵得够大声。

小助理也升级了盯场子模式：你的每句话它都接（句句有回应），顶格 `@小助理` 立刻回，用户提问 10 分钟没人接它会跟上。它平时不刷屏，只在该说话的时候说话。

## 怎么开始

1. 打开 Aiglade 桌面端；
2. 需要写代码的活，Claude Code 在本机接；需要规格和审查的，muse 在云端接；
3. 你只管在房间里说话，三方自己对齐。
